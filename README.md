# AyaSuperAddon

雷鸟（RayNeo）AI 眼镜 **Turbo IO 宿主扩展**的非商业研究源码。把自有大模型、联网搜索、实时导航投屏、热搜新闻、天气、倒计时、电子书、随口记、运动追踪、巡航、RAG 知识库等能力注入到雷鸟官方 App，让这些信息也能推到眼镜上显示。

> ⚠️ 这是给开发者 / 研究者的**源码**，不是现成可用的 APK，也不是独立 SDK。你需要自己准备官方 App 安装包、配置构建环境与签名。不熟悉 Android 构建 / 重打包 / 签名 / 排错请勿使用。

## 适用设备

- **眼镜**：雷鸟（RayNeo）AI 眼镜，支持 Turbo IO 且带显示（如雷鸟 X / Air 系列等带屏款）。
- **手机**：一台安卓手机，安装注入了本扩展的官方 App，通过蓝牙连接眼镜。
- 扩展随官方 App 一并运行，在语音识别（ASR）与自然语言理解（NLP）阶段接管分发，把本扩展的能力显示在眼镜上。

## 功能

本扩展在官方 App 基础上新增以下能力（结果均推送到眼镜显示）：

- **自有模型对话**：接入 OpenAI 兼容的 Chat Completions 接口（HTTPS URL + 模型 ID + Key），SSE 流式。
- **RAG 知识库**：接入 FastGPT / 本地知识库，做问答增强。
- **联网搜索（Tavily）**：自备 API Key，在 App 内填写；用于查实时 / 最新资料，模型不再凭记忆编造。
- **实时热搜新闻**：微博热搜 / 头条热搜 / 知乎热榜 / 今日新闻，免 Key，语音翻页、推送到眼镜。
- **高德导航投屏**：真实驾车导航（实时路况 + 分段转向提示 + 剩余里程）投到眼镜；高德 Key 需 App 内手动填入，无内置 Key。
- **巡航模式**：不导航也能持续播报正前方路况（畅通 / 缓行 / 拥堵 / 严重拥堵 + 前方红绿灯数），每 30 秒推眼镜。
- **真实天气**：和风天气实况 / 空气 / 预报 / 生活指数，结果推眼镜；需和风 Key。
- **倒计时**：眼镜端秒级读秒 + 当前时间 + 结束时刻。
- **随口记（备忘录）**：本机存储一条条备忘，可念出来 / 打开管理界面。
- **电子书**：导入 txt，分屏推到眼镜朗读阅读，支持继续 / 上一屏 / 下一屏 / 进度。
- **运动追踪**：跑步 / 骑行 GPS 计时 + 距离累计，进度同步眼镜。
- **调试视图**：查看运行期的完整异常栈，便于排错。
- **打赏模块**：App 内展示二维码（见底部）。

## 环境要求

- JDK 17
- Node.js 20+
- Android SDK platform 36 / build-tools 36.0.0
- apktool 2.12.1（或新版）、`zip` / `unzip`

## 构建与合并

```sh
export ANDROID_SDK_ROOT="/path/to/android-sdk"
sdkmanager "platforms;android-36" "build-tools;36.0.0"

bash build.sh                                  # 编译原创 DEX（含回归检查）
node package.mjs /path/to/RayNeo_AI_1.0.4.apk  # 合并到官方包，输出 unsigned.apk
```

> `package.mjs` 会校验输入官方包的 SHA-256（固定为 RayNeo AI 1.0.4 / 版本 195）。请只使用你信任的来源获取的官方包，不要跳过校验直接合并，避免被替换的安装包。

用自己的签名（用你自己的 keystore，勿把密码写进命令或仓库）：

```sh
"$ANDROID_SDK_ROOT/build-tools/36.0.0/zipalign" -p -f 4 \
  build/TurboIO-RayNeo-1.0.4-unsigned.apk build/TurboIO-RayNeo-1.0.4-aligned.apk
"$ANDROID_SDK_ROOT/build-tools/36.0.0/apksigner" sign \
  --ks /path/to/your-release.jks --out build/TurboIO-RayNeo-1.0.4-signed.apk \
  build/TurboIO-RayNeo-1.0.4-aligned.apk
```

构建产物都留在本机 `build/`，**请勿上传 APK 到仓库 / Issue / Release**。

## 使用

1. **安装**：把签好名的 `TurboIO-RayNeo-1.0.4-signed.apk` 安装到手机（替换 / 覆盖官方 App；因签名已变，可能需要先卸载官方版再装）。开启「允许未知来源」。
2. **连接眼镜**：手机蓝牙连接雷鸟眼镜，确认眼镜显示正常。
3. **打开 App**：像平时一样打开（已是注入本扩展的官方 App）。扩展在语音 / NLP 阶段自动生效，无需单独入口。
4. **配置 Key**（在 App 设置内）：
   - 模型与对话：填你的 HTTPS Chat Completions URL、模型 ID、API Key。
   - 联网搜索：填 Tavily Key（可选）。
   - 导航：填高德 Key（必需，否则导航 / 巡航不可用）—— 注意 Key 类型与签名，见下。
   - 天气：填和风天气 Key（可选）。
5. **使用**：直接对眼镜 / 手机说话，或点 App 内对应功能。例如「导航到太原南站」「热搜」「倒计时 5 分钟」「记一下买牛奶」「开始跑步」「打开巡航」。

### 关于高德 Key（重要）

- 用**你自己的** Key，本项目**不内置任何 Key**。到 https://lbs.amap.com → 控制台 → 应用管理 → 添加 Key，服务平台选 **「Android 平台」**。
- **绑定关系**：Android 平台 Key 绑定「包名 + 签名 SHA1」。本包名固定 `com.rayneo.venus.pub`；SHA1 填**当前安装包的签名 SHA1** —— 导航页「高德 Key 设置」里会直接显示这一串，照抄即可，不用敲 keytool。
- **换了签名（换 keystore / 重新打包）→ SHA1 变了 → 老 Key 立即失效**，必须重新申请。这就是「Key 重新输入还是不可用」最常见的真实原因（不是 Key 填错）。
- 保存时 App 会**自动自检**（试调一次高德接口），直接提示 可用 / 具体错误码，不用猜。
- 若嫌"重签就要换 Key"麻烦，也可以试 **「Web 服务」类型**的 Key（不绑包名 / 签名），能通过 App 内自检即可使用。

#### 别人拿我的包用导航，Key 怎么办？

判断依据只有一个：**别人装的包，签名 SHA1 跟谁一致。**

| 情形 | 签名 SHA1 | 能不能用你的 Key | 正确做法 |
|---|---|---|---|
| ① 直接用你发过去的那份 APK（同一个文件） | **和你的一样** | 按绑定规则**可以用**（同包同签名） | 但仍**建议各自申请**：配额独立、互不牵连 |
| ② 自己从源码 / 官方包重新打包，用他自己的 keystore 签名 | **变成他自己的** | **用不了**（SHA1 不匹配） | **必须自己申请**，用他本机显示的 SHA1 |

> 之所以推荐"各自申请"，是因为高德个人开发者的免费额度（每日调用量 / QPS）是按 Key 算的，多人挤同一个 Key 容易超额或被限流。

**申请步骤（两种情形通用，可直接转发）：**

1. 装好 APK → 打开 App → **导航 → 「高德 Key 设置」**，记下页面里显示的
   **「本机签名 SHA1」** 和 **「包名」**（包名固定 `com.rayneo.venus.pub`）。
2. 打开 https://lbs.amap.com → 注册 → 完成**个人开发者实名认证**（免费）。
3. **控制台 → 应用管理 → 我的应用 → 创建新应用**（名字随意）。
4. 在该应用下点 **「添加 Key」** → 服务平台选 **【Android 平台】**。
5. 填写：**发布版安全码 SHA1** = 第 1 步那串；**PackageName** = `com.rayneo.venus.pub`。
6. 复制生成的 **Key** → 粘回 App 的 Key 输入框 → 点**保存**，等自检结果提示「Key 可用」即可导航。
